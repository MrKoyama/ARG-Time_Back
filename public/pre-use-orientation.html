BEFORE FIRST USE

利用前オリエンテーション

TIME BACK FOR BUSINESSを利用するすべての従業員を対象に、仕組み、安全基準、本人の権利、実際の操作を確認します。

ORIENTATION OVERVIEW

理解してから、本人の意思で利用を始める。

法人担当者による利用者登録後、初回セッションの前に専任スタッフが説明と操作確認を行います。受講は利用条件の一つですが、受講後に利用を希望しない場合は登録を取り下げることができます。

DURATION約45分説明、確認、操作練習を含みます。
FORMAT対面またはオンライン機材を使用する場合は対面で実施します。
REQUIRED利用者本人が受講代理受講はできません。

PROGRAM

オリエンテーションの内容

01 / SERVICE

サービスと利用条件

時間プールから配分された購入時間、時間反映倍率、利用可能な目的と場所、法人契約上の制限を確認します。

02 / SAFETY

安全機能と利用上の注意

Behavior Assistance Systemによる状態確認、負荷に応じた倍率調整、安全停止、通常状態への復帰と連絡方法を説明します。

03 / OPERATION

アプリと機材の操作

TIME BACK IDによる本人確認、割当時間の確認、セッション条件の設定、開始前承認、停止操作を実際に練習します。

04 / CONSENT

取得情報と本人の権利

取得される状態・位置・利用記録、閲覧できる管理者、保存期間を確認し、利用の辞退や承認撤回の方法を案内します。

PRACTICAL CHECK

初回利用前の確認項目

説明後は、担当者とともに短時間の確認セッションを実施します。

  • 本人確認利用者本人のTIME BACK IDと法人側の登録情報が一致していることを確認します。
  • 利用条件目的、時間、時間反映倍率、利用場所、連絡先が本人の認識と一致していることを確認します。
  • 状態確認当日の体調と利用環境を確認し、必要に応じて倍率や利用時間を調整します。
  • 操作確認一時停止、緊急停止、担当者への連絡、利用履歴の確認を本人が操作します。
  • 最終承認すべての説明と設定を確認した後、利用者本人が初回セッションを承認します。

セッション中断時の取り扱い

安全上の理由や利用者の操作によりセッションが途中で終了した場合、そのセッションに割り当てられた未使用時間は失効します。TIME BACK側の障害が原因と確認された場合は、利用時間の再付与または契約条件に基づく保証を行います。

FINAL CONFIRMATION

受講だけでは、利用は開始されません。

オリエンテーション修了後も、各セッションの内容は利用者本人が確認します。法人管理者の承認のみで自動的に開始されることはありません。

  • 本人以外による承認は不可
  • セッションごとに条件を表示
  • 開始前なら承認を撤回可能
  • 本人の操作で停止可能
