# 世界観と基本ルール

制作者専用。出典の区分は [README](README.md) を参照。

## 1. 世界観・主題

【原案・継続する本筋】近未来の現実社会の延長。Chronect株式会社が「時間を売買できる」TIME BACKを運営する。便利で信用できるサービスの顔から、売却中の身体の利用、無断試験、SECOND SHIFT計画へ調査が進む。

主題は「本人が覚えていなくても、その時間はその人の人生である」。記憶と自己同一性は副題。単なる悪徳企業摘発だけで完結させない。

ARGの最終タイトル、Cloudflareプロジェクト名・公開URLは未確定。TIME BACKはサービス名であり、他社まで含む作品全体の正式題と断定しない。

## 2. 表向きのサービス説明と真相

| 項目 | 公開説明・現行実装 | 制作者側の真相・原案 |
|---|---|---|
| 時間の売買 | 売却時間を共通の時間プールへ集約し購入者へ提供 | 時間そのものの移転はない。売却側と購入側は別の処理 |
| 売却側 | 仮眠に近い状態。BASが安全な移動・姿勢維持を支援 | 記憶形成・主観時間認識を抑えた身体を行動試験に利用 |
| 購入側 | 購入時間を日常へ反映し、活動できる時間が増える | 集中・覚醒・主観時間に関わる別技術。肉体活動の設定との詳細整合は未確定 |
| BAS | Behavior Assistance System。安全な日常行動を支える | 外部から行動指示を与える制御系でもある |
| Business | 法人の時間調達・配分・利用管理・安全運用 | 記憶に残らない行動を労働力として商品化する展開へ |
| SECOND SHIFT | 公開ページにはまだ登場しない | 未公開の第二労働モデル。「労働を、人生の外側へ。」 |
| 安全性 | 同意、負荷監視、安全停止、情報保護を強調 | 長時間・高頻度利用の記憶障害を把握しながら継続する原案 |

公開企業ページで「実は別技術」「体感だけを延ばす」と説明して真相を先回りしない。基礎的な時間認知研究が載っていること自体と、サービスの正体を暴露することは区別する。

【確定・制作判断】売却者と購入者の一対一対応ではなく、時間プール方式の説明を採用。誰の時間が誰に渡ったかを特定できる設定にはしない。

## 3. 利用ルール（確定判断と現行実装）

### 売却

- 予約時刻、または即時売却の安全確認後に開始。終了までの主観的記憶は原則残らない。
- 仮眠に近い状態になるが、BASが周囲を把握し、歩行、電車の乗降、吊革につかまって立つ、着座・姿勢維持などを行える。
- 自宅のベッド・ソファなど落ち着いた環境を推奨しつつ、通勤・移動時間にも利用できる。
- 終了時は目覚めるように覚醒。緊急音・接触・危険・体調変化を検知した場合も覚醒・停止する。指定音声や緊急連絡先からの覚醒手段もFAQにある。
- 自動車・自転車の運転、危険作業中、体調不良時などは不可。通常の睡眠を代替しない。
- 中断した売却の報酬は実施状況と理由を確認して個別精算。購入側の「未使用時間消滅」と混同しない。

### 購入

- 購入時間は「追加される時間」。標準2倍なら実時間1時間＋購入時間1時間＝2時間分の活動。
- 時間反映倍率1.1〜3倍、標準2倍。公開文章は時間プールから受け取る時間として統一している。
- 購入1時間の利用に必要な実時間は、倍率2で1時間、3で30分、1.5で2時間。整理上は実時間＝購入時間÷（倍率−1）。
- 【制作判断】肉体の活動も速くなる設定を採用。ただし移転のない真相との生理学的・技術的な説明は原案に詳細がなく、追加確定しない。
- 会話・共同作業では1倍に近づけ、その間は購入時間を消費しない。終了後に設定倍率へ戻す。
- 身体負荷を検知し、自動倍率調整、強制停止、新規購入の一時制限を行う。
- 長時間購入は複数セッションに分割予約できる。自由に使う残高方式は採用しない。
- 開始済みセッションの自己都合・体調・周辺トラブルによる終了では、その枠の未使用時間は消滅。未開始の分割予約枠は残る。
- TIME BACK側の障害による終了の場合のみ未使用分を補償。長時間利用条件を承認するのは利用者本人。
- 法人も組織の承認だけでは開始せず、セッション単位の本人最終承認を必要とする。

### 公開価格（pricing.html）

| 時間 | 売却報酬 | 購入料金 |
|---|---:|---:|
| 30分 | 240円 | 900円 |
| 1時間 | 520円 | 1,650円 |
| 2時間 | 1,160円 | 3,000円 |
| 4時間 | 2,560円 | 5,400円 |
| 6時間 | 4,200円 | 7,200円 |

長い一括売却ほど報酬単価が上がり、長い一括購入ほど料金単価が下がる。memoの4時間2,560円、1時間購入1,650円・2時間3,000円と一致する。

会員は18歳以上・本人確認と事前審査が必要。Webは案内、売買と管理は架空のアプリ内。アプリ自体は実装していない。

## 5. 地理・施設・写真

【制作判断】明浜駅南口、明浜みどり公園、明浜商店街、Chronect本社、隣接するTIME BACK事業センターがある。公開アクセス図は `public/images/map.png`。

- 生活環境実証エリアは事業センター内部の屋内模擬環境。公園そのものではない。
- 秘匿研究施設は別の建物として予定。公開地図下側の無記名建物に対応させる構想だが、内部配置・住所・入口の厳密な確定図はない。
- 公開の駅からの案内は公園の抜け道を使わない。売却者の誘導経路は公園→住宅間の細道→商店街→秘匿施設という別ルート。
- この経路はBAS試作時の複雑環境テストで指定され、完成後も検証済み経路として残った設定。最短・唯一の経路にする必要はない。
- 銀色の二重リング像は「他人同士の時間が混じり合う」という抽象表現。像の正式名称・作者・建立年は未確定。
- 42番の地域清掃写真から像を見つける。企業検索で公園紹介が都合よく出る旧案は採用方針と合わない。
- 公園の所有者をChronectと断定しない。清掃協力は所有権の根拠にならない。

旧ラフ `位置関係検討図.svg` の「TIME BACK本社」「屋外実証エリア」「近道だから」という説明は後の判断で更新されている。現在設定の正本として使わない。
