### 実際に送った指示

送信した役割Markdown全文と案件指示を、作業会話の実際の起動メッセージで追跡可能にする。記録ファイルを作る場合は、その全文を保存するか、メインが到達できる実際の会話記録・保存先を参照する。後から変わり得る元ファイルのパスとハッシュだけでは全文の保存の代わりにならない。存在しない会話IDやリンクを捏造しない。

追加依頼・許可変更・着手許可も時系列で記録する。役名を名乗っただけ、ハッシュを復唱しただけの状態と、成果物まで検証した状態を区別する。
