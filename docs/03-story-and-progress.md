# ストーリー構成と現在地

## 1. 体験の大筋

以下は、原案と最新の制作判断を接続した整理。新規ページの確定発注・ページ番号の予約ではない。

| 段階 | プレイヤーの疑問・認識 | 状態 |
|---|---|---|
| 導入 | 知らない購入者が、会社員の毎朝の道を夢で見る。なぜ一致する？ | プロローグ草案・memo実装済み |
| 初期調査 | 時間と一緒に記憶まで渡っているのでは、と自分で仮説を持つ | 狙いは確定。作中で明言しない |
| 場所の同定 | 案内図の公園名と清掃写真の二重リング像が夢と対応 | 素材・検索導線あり。ただし実際の誘導精度は要テスト |
| 最初の反転 | 投稿者も売却しており、そのセッション中に自分でそこを通った | 制作判断は確定、証明する行動履歴が未実装 |
| 次の疑問 | 自宅から売った人が、なぜそこへ？BASは何をさせていた？ | Hub・記録・高瀬の細工をこれから設計 |
| 企業の構造 | 売却と購入の時間は実際には接続されていない | 原案の核。公開説明ではまだ明かさない |
| 人物へ収束 | 同じ被験者の記録が高瀬につながり、失踪と調査を知る | 原案、未実装 |
| 深層調査 | メモの検索仕様からA資料へ戻り、不正を証拠にする | 原案、未実装 |
| 捜索・告発 | 高瀬の潜入先・新しい身分を推理し、告発証拠を揃える | 大筋は原案、身分設定は要承認 |
| 結末 | 告発と高瀬発見の成否で4分岐 | 原案、フラグ・判定・画面未実装 |

最初の反転だけで「記憶は絶対に移転しない」と証明できるわけではない。まずは夢の一致に直接的な説明を与え、時間移転がない全貌は後続資料で立証する。

## 2. 現在の制作到達点

### 実装済み

- memo風架空投稿サイト2記事。夢・感想記事間の関連記事、本文のTIME BACKリンクと紹介カード。
- 個人向けサービス10ページと専用検索。売却・購入の説明、価格、規約、FAQ、ID確認画像。
- Chronect企業6ページ、ニュース個別記事14ページ、専用検索。研究は18項目。
- for Businessのサービス、事例、安全、導入、BAP、機器、オリエンテーション、実証、地域連携、屋内エリア。
- 提携企業一覧と独立した企業サイト2社。新入社員研修の活用はノードリンク、通常の活用はアクシオン。
- アーカイブ、架空サイトの注意書き、共通GA。

### 文章・設定はあるが、プレイ可能な機能ではないもの

- `プロローグ草案.md`。外部noteへの最終公開状態は今回検証していない。
- `ストーリー原案.txt`、`ページ目安.txt`のHub・高瀬・SECOND SHIFT・エンド構想。
- 秘密施設と誘導経路の制作判断。公開mapには秘密の説明を出していない。
- 管理コードの画像。コードを入力して行動履歴を表示する機能はまだない。

### 未実装

Hubの画面・資料・管理コード照会、夢の経路のログ、失踪記事、高瀬メモ、A/B/C資料群、対象者名簿、社員番号の隠しページ、告発フォーム、捜索・エンド判定。

## 3. 原案から更新された点

- 導入を、サービス一般の疑念から「購入者の夢の景色が売却者の通勤経路と一致」に変更。
- 夢投稿者は購入専用ではなく、売却もしている人物に変更。実際には本人の売却中の経験。
- 売却と購入は時間プールを介する公開説明へ統一。
- BASは移動中にも売却可能。単に安全な場所で静止するだけではない。
- 長時間購入は分割予約、残高保有なし。本人同意と失効・補償条件を明確化。
- TIME BACKから直に法人案内ではなく、Chronectを経由する調査の方向へ。
- 地域サイトや公園単独ページに頼らず、地域清掃の写真から公園の像へ。
- 生活環境実証エリアは事業センター内。公開の屋内エリアと秘密施設を分離。
- 提携企業のブランドを分離。高瀬の潜入役職は原案の派遣登録スタッフから、中途採用・Web管理を担う案へ動いている。別名の扱いは未確定。

## 4. 次に進む際の注意

既存ページ数が多いことと、ストーリーの調査ルートが完成していることは別。現在は序盤の公開情報を厚くした状態で、最初の答えを示す証拠が欠けている。

【推測・整理案】次の設計単位は「研究発表→Hubへの入口→管理コード照合→まつだの売却中の経路が判明」までに絞ると、情報の出し過ぎを抑えやすい。具体的なページ数・コード入力規則・履歴範囲・日付はユーザー承認前に確定しない。
