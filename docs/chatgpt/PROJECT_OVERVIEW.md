## 2. 作品と主題

近未来の現実社会を舞台に、時間売買サービス「TIME BACK」と運営企業Chronectの情報をWebで調べていく検索型ARG。制作上は「ARG TIME BACK」と呼んでいるが、既存資料では作品全体の最終タイトル・公開名・URLは未確定。TIME BACKは作中サービス名として確立している。

【原案・継続する本筋】便利なサービスの調査から、売却中の身体の利用、無断試験、記憶に残らない第二労働モデルSECOND SHIFT、失踪した高瀬悠真へと進む。主題は「本人が覚えていなくても、その時間はその人の人生である」。記憶と自己同一性も扱い、企業不正の摘発だけで終わらせない。

【公開説明】利用者は通勤・待ち時間などを売り、報酬を受け取れる。購入者は時間プールを通じて追加の活動時間を得る。売却者と購入者の一対一の対応は設定しない。

【制作者側の核】時間そのものの移転はない。売却側と購入側は別処理であり、売却中に記憶が残らない身体が利用されている。この真相を一般企業ページで先に説明しない。詳しい確定範囲・原案との区別はSTORY_DESIGNを参照する。

【2026-10-30追加承認・制作者情報】通常BASは安全を優先し、習慣化した行動を模倣するが、安全に休息中の人を不要に移動させない。身体動作・状況認識・判断の支援であり、思考力を直接増強しない。まつだの通常外の移動はChronectの認証済み外部指示による無自覚の秘密実験だった。秘密実験成果の一部は通常BASにも還元される。範囲・精度・個人最適化という進化を異種資料から間接的に示す方針だが、具体的な製品更新や秘密成果との対応は未確定。現行では生活動線の研究要旨No.44に加え、訪問履歴No.48とセッション対応表No.49と施設C調査編No.50〜51まで実装済み。詳細はSTORY_DESIGNと正本01・02を参照する。

【2026-11-02追加承認・実装済み】研究成果を中心に製品改善・公開実績を組み合わせ、安全支援と動作継続性・完了率・再現性という評価目的の違いを伏線にする。34の指定文、Hub検索「生活動線」→新58に加え、同日後続の作者承認で43に「生活動線や」の5文字を挿入。34＋43の共通語を自発的に検索する探索導線は実装完了。44は未変更、43は設問調査のまま。製品更新通知は未実装、発見順は強制せず初見未検証。研究間の同一性や人物・秘密の直接的な答えは追加しない。

## 5. 遊び方と制作方針

プレイヤーは本文を読み、通常リンク、サイト内検索、画像拡大、画面のフォーム、資料照合で進む。ソースコード、開発者ツール、内部データ、URL推測・総当たりを解法にしない。

検索はサイト別の完全一致ホワイトリストで、全文検索ではない。同じ語句でもサイトごとに結果が異なる。資料や人物の痕跡がWebに存在する理由を設計する。

序盤の仮説は「時間と一緒に記憶も渡るのでは」。本文でそう言わせず、景色の一致からプレイヤーに考えさせる。最初の反転は「夢の投稿者本人が、売却中にその場所を訪れていた」。写真の枝と記録の枝を自分で照合する体験を守る。

企業サイトは普通でクリーンに見せる。露骨な不穏演出、正解語の強調、謎の印を加えない。各社のブランドを区別し、ページアーカイブだけは白・グレーで共通化する。ページ番号は閲覧の目安で、必須攻略順ではない。
