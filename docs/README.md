## 状態の読み方

| 表記 | 意味 |
|---|---|
| 確定・制作判断 | ユーザーが明示的に決めた設定・方針。未実装でもよい |
| 実装確認 | 現在のHTML・JS・画像に存在する事実。世界内の説明が真実とは限らない |
| 原案 | 既存企画・ストーリー案に記載。後の変更に優先せず、未実装部分の最終確定を保証しない |
| 推測・整理案 | 調査から導いた解釈や作業提案。承認済み設定に昇格させない |
| 未確定 | 根拠不足・未決定・複数案の衝突がある状態 |

「公開サイトが語る説明」「制作者が知る真相」「プレイヤーがその時点で知る情報」を必ず分けて扱います。

## 判断の優先順位

現在のユーザー指示 → 最新の明示的な制作判断 → 既存の承認済みブランド設定 → 現行実装 → 古い原案・画像プロンプト、の順に照合します。食い違いは黙って一本化せず、未確定事項へ記録し、重要変更はユーザーに確認してください。
